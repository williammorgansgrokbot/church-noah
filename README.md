# Noah's Big Boat – class art edition

**▶ Play now (iPad, phone, or any Windows PC / Mac browser):** https://williammorgansgrokbot.github.io/church-noah/

**⬇ Windows PC or Mac app (with Big Screen mirroring + add-your-class-art tools):** https://github.com/williammorgansgrokbot/church-noah/releases/latest
- Windows: `NoahsBigBoat_Windows.zip` — unzip and double-click `Noah's Big Boat.exe` (SmartScreen: More info > Run anyway).
- Mac (Apple silicon): `NoahsBigBoat_Mac.zip` — unzip, then right-click `Install Noah (Mac).command` > Open. It copies the app to ~/Applications, clears quarantine and opens it.
  If macOS says the app "is damaged" (it is ad-hoc signed, not notarized): open Terminal, paste `xattr -cr ~/Downloads/"Noah's Big Boat/Noah's Big Boat.app"` (or type `xattr -cr ` and drag the app in), press Return, then double-click the app. Fallback: System Settings > Privacy & Security > "Open Anyway".
  The GitHub key is stored in the macOS Keychain (Windows: Credential Manager); data lives in ~/Library/Application Support/NoahsBigBoat.

<sub>ℹ️ [About this program](https://williammorgansgrokbot.github.io/church-noah/about/) (overview for church leaders)</sub>

## Teacher notes
- Open the Play link on an iPad and tap **📱 Tap to enable TILT** during the flood and dove levels (or just use a finger).
- The web version runs entirely in the browser; nothing to install. Live mirroring to a projector needs the Windows or Mac app (see `START HERE.pdf` in the release).
- Print *Coloring pages (print me).pdf* from the release for the kids to draw animals.
- **Note:** the class art currently in the game is placeholder test art; replace it with your class's drawings using the Windows or Mac app.
